# NumPy Dtype Memory & Performance Benchmark Lab

Benchmarking NumPy dtypes (int8 to int64, float16 to float64) for memory, speed and precision on 1-million-element arrays.

## Problem
How does dtype choice affect memory usage, execution speed and numerical precision?

## Approach
1. Created the same 1M-element array in 7 dtypes
2. Compared `size`, `itemsize` and `nbytes` in a table
3. Timed `sum` and `multiply` with `timeit`
4. Demonstrated integer overflow and float precision loss with `astype()`
5. Plotted memory vs time and wrote dtype recommendations

## Key Findings
- int8 uses **8x less memory** than int64 (1 MB vs 8 MB for 1M elements)
- Integer overflow: `200` cast to int8 becomes `-56`
- float16 loses precision quickly (`float16(2049)` becomes `2048`) and its sum overflows to `inf`
